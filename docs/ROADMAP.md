# Project Roadmap

## Phase 0: Foundations

- Core ECS setup and Data-Oriented structures.
- Linear algebra integration and unit standardization.

## Phase 1: Kinematics & Integration

- Implementation of higher-order numerical integrators (RK4).
- Linear translational motion and force accumulation systems.

## Phase 2: Celestial Dynamics (Macro)

- Newtonian N-Body gravitational simulation.
- Orbital mechanics and trajectory prediction.

## Phase 3: Computational Optimization

- Spatial partitioning via Octrees.
- Barnes-Hut algorithm implementation for $O(n \log n)$ complexity.

## Phase 4: Fluid & Thermodynamics

- Smoothed Particle Hydrodynamics (SPH) for gas/star simulation.
- Heat transfer and state equation solvers.

## Phase 5: Hardware Accelerated Rendering

- wgpu pipeline for mass-instance rendering of particles and spheres.
